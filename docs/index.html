CWI Proof Embed

Any site can embed a "verified by CWI" badge for a track claim — backed by a live verification record, and honest about staleness. When the claim goes stale, the badge visibly degrades. There is no permanent checkmark.

Integrate in 3 steps

  1. Pick a claim. Browse the backed claims at the records directory, or ask CWI to back a new claim (every record carries claim text, evidence tier, observed_at, and a freshness window).
  2. Paste one snippet where you want the badge: 
    <script src="https://cumulativewebinc.github.io/cwi-proof-embed/badge.js"
        data-claim="zooted-zone-eric-alper"></script>
  3. Done. The badge fetches its record on every page load, renders VERIFIED / STALE / UNVERIFIED from the dates, and links to the verifier page — the record of truth. Zero dependencies, ~7KB, no cookies, no tracking.

How honesty is enforced

  • The badge never renders "verified" without a live backing record whose observed_at is a strict ISO-8601 timestamp inside its TTL.
  • Fetch failure, malformed record, future-dated observation, tampered claim id → UNVERIFIED — recheck. Fail closed, always.
  • Claim ids are allow-listed to [a-z0-9-]; path traversal is rejected before any fetch.
  • Claim text is rendered via textContent — badge markup cannot be injected through a record.
  • Records are refreshed by CWI's daily pipeline; stale windows are public in each record.
